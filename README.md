# momma-updates

Update channel for Momma's Theater. The Momma Updater app on the TV box reads `update.json` from the latest release here.

- Releases are tagged by MommaTheater versionCode (e.g. `vc40`).
- `update.json` lists the app version, download URL, SHA-256 and size. The updater installs only newer versions signed with the same key as the installed app.
- No family videos are stored here.
